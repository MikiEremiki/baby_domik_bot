# Session Continuous Skill

Непрерывные сессии для связанных задач — меньше потери контекста.

Этот скилл помогает объединять связанные задачи в одну сессию, чтобы Junie сохраняла контекст и работала эффективнее.

## Когда использовать

- У пользователя несколько связанных задач
- Задачи касаются одних и тех же файлов или модулей
- Пользователь работает в ночное время и хочет оставить Junie работать автономно
- Задачи логически связаны (например, «добавить фичу», «написать тесты», «обновить документацию»)

## Почему непрерывные сессии важны

На основе аудита ваших сессий:

- **9 сессий за одну ночь** (02.10.2026, 00:40–02:35) — все касались `baby_domik_bot` и были короткими. Одна сессия решила бы всё быстрее.
- **baby_domik_bot 01.10.2026** — 15+ сессий за день, многие касались смежных файлов (handlers, API, шаблоны). Объединение в 2-3 сессии сэкономило бы время.
- **Админка baby_domik_bot** — велась в 5+ разных сессиях. Каждая новая сессия — потеря контекста.

**Ожидаемый эффект:** Меньше потери контекста, быстрее выполнение серии связанных задач.

## Как использовать session-continuous

### 1. Один промпт — несколько задач

Вместо:
> Сессия 1: «Добавить кнопку X»
> Сессия 2: «Добавить обработчик Y»
> Сессия 3: «Обновить документацию»

Используйте:
> «Сделай 3 вещи: 1) Добавить кнопку X, 2) Добавить обработчик Y, 3) Обновить документацию. Не выводи план в чат, я посмотрю в финальном файле.»

### 2. Ночные сессии

Для ночной работы используйте одну длинную сессию с чётким списком задач:

> «У меня есть 5 задач на tonight. Реализуй их все в этой сессии по порядку:
> 1) Добавить админку для цен
> 2) Обновить API эндпоинты
> 3) Написать тесты
> 4) Обновить документацию
> 5) Закоммитить изменения
> 
> Не выводи план в чат, я его посмотрю в финальном файле.»

### 3. Подключение к предыдущей сессии

Если сессия стала слишком длинной, но задачи всё ещё связаны:

- Подключитесь к предыдущей сессии через `junie://sessions/<id>`
- Или продолжите в той же сессии, перечислив оставшиеся задачи

## Советы

1. **Группируйте по модулю** — задачи, касающиеся одного модуля, делайте в одной сессии
2. **Чёткий список задач** — перечислите все задачи в одном промпте
3. **Приоритеты** — укажите порядок выполнения, если он важен
4. **Автономность** — если вы цените готовый результат, скажите «не выводи план в чат»
5. **Ограничение длины** — если сессия становится слишком длинной (50+ сообщений), лучше создать новую, но с полным контекстом

## Примеры промптов

**Множественные задачи:**
> «Сделай 3 вещи в этой сессии:
> 1) Добавить валидацию телефона в бронирование
> 2) Обновить API для создания бронирования
> 3) Добавить обработку ошибок в webhook YooKassa»

**Ночная сессия:**
> «Реализуй эти задачи автономно:
> 1) Создать ветку feature/booking-validation
> 2) Реализовать валидацию бронирования
> 3) Написать тесты
> 4) Обновить документацию и закоммитить
> 
> Не прерывай меня, просто сделай всё по порядку.»

**Продолжение работы:**
> «Продолжим работу над бронированием. Осталось:
> 1) Добавить уведомления в Telegram
> 2) Добавить рассылку по продажам
> 3) Обновить документацию»
