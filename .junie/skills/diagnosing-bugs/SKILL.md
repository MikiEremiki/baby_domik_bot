# Diagnosing Bugs

Систематическая диагностика багов через цикл обратной связи: создайте минимальный воспроизводящий случай, изолируйте проблему, найдите причину, исправьте.

## Процесс

### 1. Воспроизвести

Создайте минимальный способ воспроизвести баг:

- **Что ожидалось:** конкретное ожидаемое поведение
- **Что произошло:** фактическое поведение
- **Как воспроизвести:** шаги, данные, условия

Если баг уже воспроизводится (тест, пользовательский отчёт), перейдите к шагу 2.

### 2. Изолировать

Сузьте область поиска:

- **Бисекция:** отключайте половины системы, пока не найдёте минимальный набор, который воспроизводит баг
- **Логирование:** добавьте логирование в ключевые точки, чтобы увидеть, где поведение отклоняется
- **Гипотезы:** сформулируйте гипотезы о причине и проверьте каждую

### 3. Найти причину

Когда изолировали область:

- **Чтение кода:** изучите изолированную область детально
- **Сравнение с ожидаемым:** где код отклоняется от ожидаемого поведения
- **Проверка предположений:** какие предположения в коде неверны

### 4. Исправить

- **Регрессионный тест:** напишите тест, который воспроизводит баг (fails before, passes after)
- **Фикс:** минимальное исправление, которое проходит тест
- **Проверка:** убедитесь, что фикс не ломает существующее поведение

## Чек-лист

- [ ] Баг воспроизводится детерминированно?
- [ ] Минимальный воспроизводящий случай создан?
- [ ] Область изолирована (бисекция)?
- [ ] Гипотезы сформулированы и проверены?
- [ ] Причина найдена и понятна?
- [ ] Регрессионный тест написан?
- [ ] Фикс минимальный и проходит тест?
- [ ] Существующее поведение не сломано?

## Адаптация для Junie

- **Тесты:** используйте `uv run python -m unittest` для запуска тестов
- **Логирование:** добавьте временное логирование, удалите после диагностики
- **GLOSSARY.md:** используйте `docs/GLOSSARY.md` для терминов проекта
- **Регрессии:** после исправления зафиксируйте в `.junie/audit/REGRESSIONS.md` через `/task-check --regression`

## Советы

- **Не угадывайте:** каждый шаг должен быть основан на证据, не на догадках
- **Один баг за раз:** не пытайтесь исправить несколько багов одновременно
- **Регрессионный тест обязателен:** без теста баг вернётся
