# Каталог скиллов BabyDomikBot

Скиллы загружаются автоматически при релевантности задаче. Полный список доступен через `/skills` в чате Junie.

---

## Основные скиллы разработки

| Скилл | Назначение | Когда использовать |
|-------|-----------|-------------------|
| [implement](implement/SKILL.md) | Структурированная реализация задачи | После `/task-check` или `/to-spec` |
| [code-review](code-review/SKILL.md) | Двухосный код-ревью | После реализации, перед коммитом |
| [task-check](task-check/SKILL.md) | Проверка задачи перед реализацией | Перед началом любой задачи |
| [commits](commits/SKILL.md) | Создание веток и коммиты | После `/code-review` |

## Уточнение задач

| Скилл | Назначение | Когда использовать |
|-------|-----------|-------------------|
| [grill-with-docs](grill-with-docs/SKILL.md) | Опрос с фиксацией в docs/ | Задача неоднозначна, нужен ADR |
| [grilling](grilling/SKILL.md) | Бескомпромиссный опрос | Нужно протестировать мысли |
| [grill-me](grill-me/SKILL.md) | Быстрый опрос без фиксации | Быстрое уточнение |
| [to-spec](to-spec/SKILL.md) | Создание спецификации | После grill, перед реализацией |
| [to-tickets](to-tickets/SKILL.md) | Декомпозиция на тикеты | Крупная задача, нужен план |
| [wayfinder](wayfinder/SKILL.md) | Карта решений для крупных задач | Задача больше одной сессии |
