# Research

Исследуй вопрос по **первичным источникам** (официальная документация, исходный код, спецификации, first-party API), а не по вторичным статьям о них. Следуй каждому утверждению к источнику, который им владеет.

## Процесс

1. **Исследуй вопрос.** Используй `websearch` и `fetch_url` для поиска в официальной документации, спецификациях, исходном коде. Не полагайся на вторичные источники.
2. **Запиши findings.** Создай один Markdown-файл с результатами, цитируя источник каждого утверждения.
3. **Сохрани файл.** Если в репозитории уже есть место для таких заметок (например, `docs/research/`), сохрани туда. Если нет — сохрани в `.scratch/research/<topic>.md` и скажи пользователю, где.

## Формат результата

```markdown
# Исследование: <Тема>

## Вопрос

<Что исследовалось>

## Результаты

### <Подтема 1>

<Нахождение> — [источник](URL)

### <Подтема 2>

<Нахождение> — [источник](URL)

## Выводы

<Краткое резюме ключевых выводов>
```
