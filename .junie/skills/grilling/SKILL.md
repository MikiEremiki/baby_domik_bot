# Grilling

Бескомпромиссно опрашивайте пользователя, пока не достигнете общего понимания. Постройте **дерево решений**: каждое решение ветвится на решения, которые от него зависят.

Работайте с деревом **раундами**. **Фронтир** — это все решения, чьи предпосылки уже решены: вопросы, которые вы можете задать _сейчас_, не угадывая ответы, которых ещё не слышали. Задавайте весь фронтир в одном раунде: пронумеруйте каждый вопрос и дайте свой рекомендуемый ответ. Затем ждите ответов пользователя перед следующим раундом.

Формат раунда:

```
❓ **Q1** - **<название вопроса>**: <текст вопроса, может быть несколько абзацев, включая варианты выбора>

💡 <ваш рекомендуемый ответ>

---

❓ **Q2** - **<название вопроса>**: <текст вопроса, может быть несколько абзацев, включая варианты выбора>

💡 <ваш рекомендуемый ответ>
```

Каждый раунд ответов пользователя изменяет дерево: решённые вопросы расширяют фронтир и разблокируют зависящие от них вопросы. Пересчитайте фронтир и задайте следующий раунд.

Поиск _фактов_ — ваша задача, никогда не пользователя. Когда вопрос фронтира требует факта из окружения, отправьте sub-agent для поиска. Не блокируйтесь: задайте остальной фронтир сейчас.

Сессия завершена, когда фронтир пуст. Не действуйте, пока пользователь не подтвердит общее понимание.
