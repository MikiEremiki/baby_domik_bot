# 13. Аудит Telegram UI (Telegram UI Audit)

> **Приоритет:** 🟡 Средний
>
> **Новый чеклист для baby_domik_bot:** проверка клавиатур, inline-кнопок и сообщений бота.

---

## Чек-лист

- [ ] Inline-клавиатуры — `src/utilities/utl_kbd.py`: используются ли функции утилиты вместо ручного создания?
- [ ] Кнопки «Назад» и «Отмена» — везде ли используется `add_btn_back_and_cancel`?
- [ ] Callback data — нет ли переполнения (лимит 64 байта)?
- [ ] Сообщения бота — нет ли XSS через HTML-форматирование с пользовательским вводом?
- [ ] Длинные сообщения — разбиваются ли на части (>4096 символов)?
- [ ] Состояния диалога — корректно ли обрабатывается выход из ConversationHandler?
- [ ] Таймауты — обрабатываются ли таймауты ожидания ответа пользователя?
- [ ] Локализация — все ли сообщения на русском языке, без английских артефактов?
