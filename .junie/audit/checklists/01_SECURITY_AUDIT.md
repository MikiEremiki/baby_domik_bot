## Чек-лист

- [ ] XSS-уязвимости — проверить экранирование вывода во всех HTML-рендерерах
- [ ] SQL-инъекции — при добавлении БД использовать параметризованные запросы
- [ ] File upload уязвимости — валидация типа/размера загружаемых Excel-файлов
- [ ] CSRF-защита — наличие CSRF-токенов для FastAPI
- [ ] Информационное раскрытие — stack trace не должен попадать в API-ответы
- [ ] Заголовки безопасности — `X-Content-Type-Options`, `X-Frame-Options`, `CSP`
- [ ] Аутентификация — админ-эндпоинты без защиты
