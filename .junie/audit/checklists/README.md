## Как используются

Шаблоны **не исполняются напрямую**. Они используются AI-агентом при аудите задачи:

1. Вы вызываете `/task` с описанием задачи
2. Агент определяет, какие шаблоны затронуты
3. Проверяет задачу по соответствующим шаблонам
4. Создаёт **отчёт** в [`../reports/`](../reports/) с результатами
5. Обновляет **статистику** в [`../STATISTICS.md`](../STATISTICS.md)

Для **глубокого периодического аудита** (уровень 3) агент проходит по шаблону полностью, проверяя все пункты.

---

## Для разработчика

1. Начните с 🔴 Высокий приоритет при глубоком аудите
2. Переходите к 🟡 Средний, когда критические проблемы решены
3. 🟢 Низкий приоритет — улучшаемость, не блокирует работу
