# Шаблон системы аудитов для нового проекта

> **Назначение:** Скопируйте эту папку `.junie/audit/` в новый проект и адаптируйте по инструкции ниже.

---

## Инструкция по настройке

### Шаг 1: Скопируйте папку

Скопируйте всю папку `.junie/audit/` из текущего проекта в корень нового проекта.

### Шаг 2: Адаптируйте каталог видов аудитов

Откройте `terms/AUDIT_TYPES.md` и:

1. **Удалите нерелевантные виды** — например, если проект без БД, уберите SQL-инъекции
2. **Добавьте специфичные виды** — например:
   - Mobile-приложение: battery usage, offline mode
   - Data-pipeline: data quality, schema validation
   - Embedded: memory footprint, real-time constraints
3. **Обновите примеры** — замените пути к файлам на актуальные для нового проекта

### Шаг 3: Создайте файлы аудитов

Для каждого вида аудита из `terms/AUDIT_TYPES.md` создайте файл:

```
01_[НАЗВАНИЕ]_AUDIT.md
02_[НАЗВАНИЕ]_AUDIT.md
...
```

Используйте следующий шаблон для каждого файла:

```markdown
# [Название аудита]

> **Приоритет:** 🔴/🟡/🟢
> **Статус:** ⏳ Ожидает

---

## Чек-лист

- [ ] [Пункт 1 из AUDIT_TYPES.md]
- [ ] [Пункт 2 из AUDIT_TYPES.md]
- [ ] [Пункт 3 из AUDIT_TYPES.md]

---

## Найденные проблемы

(пока пусто — проведите первый аудит)

---

## Рекомендации

(пока пусто — проведите первый аудит)
```

### Шаг 4: Адаптируйте скилл task-check

Откройте `.junie/skills/task-check/SKILL.md` и:

1. **Обновите edge-кейсы** — замените примеры на специфичные для вашего проекта:
   - Веб-приложение: XSS, CSRF, валидация ввода
   - Desktop-приложение: доступ к файловой системе, права
   - API-сервис: rate limiting, аутентификация

2. **Обновите примеры** — замените пути к файлам на актуальные

### Шаг 5: Настройте REGRESSIONS.md

Файл `REGRESSIONS.md` уже создан и пуст. При первом исправлении бага AI-агент начнёт добавлять регрессионные заметки.

### Шаг 6: Обновите README.md

Откройте `README.md` и:

1. **Обновите таблицу аудитов** — замените названия и ссылки на ваши файлы
2. **Удалите раздел "Архив"** — если нет старых аудитов
3. **Обновите "Каталог видов"** — ссылка на ваш `terms/AUDIT_TYPES.md`

---

## Что универсально (не требует адаптации)

- **skills/task-check/** — структура проверки задач универсальна, нужны только edge-кейсы
- **skills/session-check/** — управление сессиями работает для любого проекта
- **REGRESSIONS.md** — формат регрессионных заметок универсален

## Быстрый старт после настройки

1. Откройте PyCharm с новым проектом
2. В чате Junie напишите:
   ```
   /task-check
    
   Задача: [первая задача в новом проекте]
   ```
3. AI-агент проверит, что все файлы аудитов на месте и проведёт аудит
