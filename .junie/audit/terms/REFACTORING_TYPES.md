# Виды рефакторинга — универсальный справочник

Универсальный справочник содержит все основные виды рефакторинга, сгруппированные по категориям. Не привязан к конкретному проекту.

---

## Структурные рефакторинги

1. **Extract Method/Function** — выделение части кода в отдельную функцию
2. **Inline Method** — замена короткой функции её телом
3. **Extract Class** — выделение группы полей/методов в отдельный класс
4. **Inline Class** — объединение маленького класса с родительским
5. **Decompose Conditional** — упрощение сложных условий
6. **Replace Temp with Query** — замена временных переменных на методы
7. **Introduce Explaining Variable** — выделение сложного выражения в переменную с поясняющим именем

## Объектно-ориентированные рефакторинги

8. **Replace Inheritance with Delegation** — замена наследования на делегирование
9. **Replace Delegation with Inheritance** — замена делегирования на наследование
10. **Pull Up Method/Field** — перемещение в родительский класс
11. **Push Down Method/Field** — перемещение в дочерний класс
12. **Replace Type Code with Subclass/State** — замена кода типа на подкласс/состояние
13. **Replace Subclass with Delegate** — замена подкласса на делегат

## Данные и типы

14. **Replace Map with Object** — замена словаря на объект с полями
15. **Replace Object with Map** — замена объекта на словарь
16. **Change Reference to Value** — замена ссылки на значение (immutable)
17. **Change Value to Reference** — замена значения на ссылку
18. **Split Phase Method** — разделение метода на фазы с промежуточным объектом

## Архитектурные рефакторинги

19. **Separate Concerns** — разделение ответственности между модулями
20. **Dependency Injection** — внедрение зависимостей вместо глобального состояния
21. **Strategy Pattern** — замена условной логики на стратегии
22. **Factory Pattern** — выделение создания объектов в фабрику
23. **Observer Pattern** — добавление механизма уведомлений
24. **Remove Global State** — устранение глобальных переменных

## Качество кода

25. **Rename** — улучшение именования переменных, методов, классов
26. **Extract Constants** — выделение магических чисел в константы
27. **Encapsulate Field** — инкапсуляция полей через геттеры/сеттеры
28. **Remove Dead Code** — удаление неиспользуемого кода
29. **Consolidate Duplicate Code** — устранение дублирования
30. **Reduce Cyclomatic Complexity** — снижение сложности условий

## Безопасность и надежность

31. **Add Input Validation** — добавление валидации входных данных
32. **Add Error Handling** — добавление обработки ошибок
33. **Add Logging** — добавление логирования
34. **Add Rate Limiting** — ограничение частоты запросов
35. **Add Authentication/Authorization** — добавление аутентификации

## Тестирование

36. **Add Test Coverage** — увеличение покрытия тестами
37. **Refactor for Testability** — рефакторинг для лучшей тестируемости
38. **Mock External Dependencies** — мокирование внешних зависимостей
