# Примеры аудитов из текущего проекта

Конкретные примеры из кода проекта `baby_domik_bot`, иллюстрирующие каждый вид аудита из [AUDIT_GUIDE.md](AUDIT_GUIDE.md).

## 🔴 Высокий приоритет

### 1. Аудит безопасности (Security Audit) [→ справочник](AUDIT_GUIDE.md#security)

| Категория | Пример из проекта | Файл | Статус |
|-----------|-------------------|------|--------|
| **SQL-инъекции** | SQLAlchemy ORM используется, риск низкий | `src/db/` — параметризованные запросы | ✅ Нет риска |
| **XSS в Telegram** | HTML-сообщения без экранирования | `src/handlers/` — `parse_mode="HTML"` с пользовательскими данными | ⚠️ Риск |
| **CSRF в FastAPI** | Вебхуки без проверки источника | `src/api/web/routes/` — нет CSRF-токенов | ⚠️ Риск |
| **Секреты в коде** | Токены в settings.yml | `config/settings.yml` — токены бота, YooKassa, Timeweb | ⚠️ Проверить .gitignore |
| **Аутентификация** | Админские команды без проверки | `src/handlers/` — `filter_admin` используется | ✅ В порядке |
