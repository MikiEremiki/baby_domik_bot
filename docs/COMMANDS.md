# Справочник команд бота

Актуальный список всех команд Telegram-бота Бэби-театра «Домик» с указанием ролей, которым они доступны.

## Клиентские команды

Доступны всем пользователям без ограничений.

| Команда | Описание | Доступно для | Замечания |
|---------|----------|--------------|-----------|
| `/start` | Запустить бота | Все | Приветственное сообщение, описание бота |
| `/help` | Показать справку | Все | Выводит разные команды в зависимости от роли |
| `/reset` | Сбросить текущее состояние | Все | Отменяет активные брони и очищает контекст |
| `/reserve` | Забронировать место на спектакль | Все | Основной сценарий бронирования |
| `/birthday` | Забронировать день рождения | Все | Оформление заявки на ДР |
| `/bd_paid` | Оплатить день рождения | Все | Вызов после оформления ДР |
| `/tickets` | Показать мои билеты | Все | Через меню настроек (profile) |
| `/echo` | Узнать id чата | Все | ⚠️ Показана только dev в /help |
| `/rcl` | Запросить контакт и местоположение | Все | ⚠️ Показана только dev в /help |

## Разница между `/start` и `/reset`

| Аспект | `/start` | `/reset` |
|--------|----------|----------|
| **Назначение** | Первоначальный запуск бота | Сброс текущего состояния |
| **Проверка пользователя в БД** | ✅ `check_user_db` | ❌ |
| **Отмена билетов** | ✅ `cancel_tickets_db_and_gspread` | ✅ `cancel_tickets_db_and_gspread` |
| **Очистка контекста** | ✅ `clean_context` + `clean_context_on_end_handler` | ✅ `clean_context_on_end_handler` |
| **Инициализация user_data** | ✅ Устанавливает `user` и `common_data` | ❌ |
| **Приветственное сообщение** | ✅ Полное приветствие с описанием бота | ❌ Короткое: "Попробуйте выполнить новый запрос" |
| **Удаление клавиатуры** | ✅ `ReplyKeyboardRemove()` | ❌ |
| **Когда использовать** | Первый запуск, повторный запуск после блокировки | Прерывание текущего диалога/бронирования |

**Кратко:** `/start` — полный перезапуск с приветствием и инициализацией; `/reset` — быстрый сброс текущего диалога с отменой активных броней.

## Источники

- `config/settings.py` — COMMAND_DICT, ADMIN_ID, SUPERADMIN_CHAT_ID
- `src/custom_filters/admin.py` — фильтры прав доступа
- `src/setup_bot_handlers.py` — регистрация всех хендлеров, мидлварей и хуков
- `src/handlers/main_hl.py` — реализация start, reset, help_cmd
- `src/conv_hl/` — conversation handlers для всех команд
