# Шпаргалка: типы рассылок

Быстрая памятка для выбора типа рассылки в боте.

| # | Тип | Кого найдёт | Когда выбрать | Пример |
|---|---|---|---|---|
| 1 | **Свободные места на спектакль** | Люди, которые **были** на этом или похожем спектакле в этом году | Нужно предложить свободные места тем, кто уже ходил | «Вы были на "Колобке" — открылись места на новую дату!» |
| 2 | **По возрасту детей** | Родители детей определённого возраста по **всей истории** билетов | Нужны все родители детей X лет, без привязки к дате | «Для родителей малышей 1–3 лет: открылась запись на развивающий сеанс» |
| 3 | **По обладателям билетов** | Любой отбор: по статусу, спектаклю, типу, сеансу, возрасту, конкретным ID | Нужна точечная рассылка с гибкими фильтрами | «Тем, у кого билет на "Снегурочку" со статусом "Оплачен" — и предложить свободные места» |
| 4 | **Посетители сезона** | Пользователи, связанные с билетами на **прошедшие сеансы за указанный период** (включая неактивные спектакли) | Нужны все, у кого есть билеты за конкретный период; можно отфильтровать по спектаклям, возрасту ребёнка и статусам | «Всем, кто покупал билеты с февраля по январь: опрос и скидки» |

---

## Быстрый выбор

```
Нужно допродать тем, кто уже был?          → Тип 1
Нужны родители детей X лет?               → Тип 2
Нужна точечная рассылка с фильтрами?      → Тип 3
Нужны все посетители за период?           → Тип 4
```

## Краткие отличия

- **Тип 2** ищёт по возрасту без ограничения по времени — вся история билетов.
- **Тип 4** всегда требует период прошедших сеансов (две даты), позволяет фильтровать по спектаклям (включая неактивные), возрасту ребёнка в билете и статусам. Период относится к дате сеанса, а не к покупке; наличие билета не гарантирует фактическое посещение.
- **Тип 3** — самый гибкий: можно задать любой набор фильтров, ввести ID билетов вручную и прикрепить спектакль со свободными местами.
- **Тип 1** — самый простой: выбрал спектакль → получил аудиторию тех, кто был.
