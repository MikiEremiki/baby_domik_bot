# Шпаргалка: типы рассылок

Быстрая памятка для выбора типа рассылки в боте.

| # | Тип | Кого найдёт | Когда выбрать | Пример |
|---|---|---|---|---|
| 1 | **Свободные места на спектакль** | Люди, которые **были** на этом или похожем спектакле в этом году | Нужно предложить свободные места тем, кто уже ходил | «Вы были на "Колобке" — открылись места на новую дату!» |
| 2 | **По обладателям билетов** | Любой отбор: по статусу, спектаклю, типу, сеансу, возрасту, конкретным ID | Нужна точечная рассылка с гибкими фильтрами | «Тем, у кого билет на "Снегурочку" со статусом "Оплачен" — и предложить свободные места» |
| 3 | **Посетители сезона** | Пользователи, связанные с билетами на **прошедшие сеансы за указанный период** (включая неактивные спектакли) | Нужны все, у кого есть билеты за конкретный период; можно отфильтровать по спектаклям, возрасту ребёнка и статусам | «Всем, кто покупал билеты с февраля по январь: опрос и скидки» |

---

## Быстрый выбор

```
Нужно допродать тем, кто уже был?          → Тип 1
Нужна точечная рассылка с фильтрами?      → Тип 2
Нужны все посетители за период?           → Тип 3
```

## Краткие отличия

- **Тип 3** всегда требует период прошедших сеансов (две даты), позволяет фильтровать по спектаклям (включая неактивные), возрасту ребёнка в билете и статусам. Период относится к дате сеанса, а не к покупке; наличие билета не гарантирует фактическое посещение.
- **Тип 2** — самый гибкий: можно задать любой набор фильтров, ввести ID билетов вручную и прикрепить спектакль со свободными местами.
- **Тип 1** — самый простой: выбрал спектакль → получил аудиторию тех, кто был.

## Общие шаги после формирования аудитории

1. **Прикрепить спектакль** (опционально) — добавляет блок со свободными местами.
2. **Медиа** — отправить фото, видео или анимацию (до 10 штук, фото до 3-х объединяются в альбом).
3. **Текст** — подпись к медиа (до 1024 символов) или отдельное сообщение (до 4096).
4. **Проверка длины** — при превышении лимита показывается разбор символов с кнопками исправления.
5. **Предпросмотр** — 👁 сообщение администратору с кнопками «Запустить», «Отменить», «Изменить».
