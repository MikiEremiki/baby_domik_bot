## Шаги медиа → текст → предпросмотр

После формирования аудитории все типы рассылок проходят общие шаги:

1. **Прикрепить спектакль** (опционально) — добавляет блок со свободными местами и кнопку покупки.
2. **Медиа** — отправка фото, видео или анимации. Медиа накапливаются (до 10 штук), фото до 3-х объединяются в альбом.
3. **Текст** — ввод текста сообщения. Текст может быть подписью к медиа (caption, лимит 1024 символа) или отдельным сообщением (лимит 4096 символов).
4. **Проверка длины** — если текст превышает лимит, показывается разбор символов (буквы, пробелы, эмодзи и т.д.) с кнопками: «Сократить», «Перенести в отдельное сообщение», «Отправить как есть».
5. **Предпросмотр** — сообщение отправляется администратору с заголовком 👁 и кнопками: «Запустить», «Отменить», «Изменить текст», «Изменить расписание».
6. **Запуск** — при нажатии «Запустить» проверяется статус кампании (должен быть `draft`), публикуется задача в очередь и статус меняется на `running`.

## Когда использовать каждый тип

### 1. WAS_THIS_YEAR_ON_PLAY
- Цель: предложить свободные места на спектакль тем, кто уже посещал похожие спектакли.
- Подходит для: повторных продаж, cross-selling между спектаклями.

### 2. TICKET_HOLDERS
- Цель: максимальная гибкость отбора аудитории.
- Подходит для: точечных рассылок по конкретным билетам, статусам, типам мероприятий.
- Уникальная возможность: ввод ID билетов вручную.

### 3. SEASON_TICKET_HOLDERS
- Цель: отобрать всех посетителей за конкретный период.
- Подходит для: анализа сезонной активности, рассылок по итогам сезона.
- Особенности: обязательный период, все статусы билетов, доступ к неактивным спектаклям, возраст по `Child.age`.
