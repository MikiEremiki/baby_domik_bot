# Сравнительная таблица типов рассылок

| Параметр | 1. WAS_THIS_YEAR_ON_PLAY | 2. CHILDREN_AGE | 3. TICKET_HOLDERS | 4. SEASON_TICKET_HOLDERS |
|---|---|---|---|---|
| **Название** | Рассылка о свободных местах на выбранный спектакль | Рассылка по возрасту детей (история билетов) | Рассылка по обладателям билетов (с фильтрами) | Рассылка посетителям сезона (билеты за период) |
| **Описание** | По людям, которые посещали спектакль/спектакли | Отбор по возрасту детей по всей истории билетов | Гибкий отбор по статусам, спектаклям, типам, сеансам, возрасту | Отбор по посетителям за указанный период |
| **Первый шаг** | PICK_THEATER (выбор спектакля) | PICK_CHILD_AGE_MIN (минимальный возраст) | PICK_FILTERS (выбор фильтров) | PICK_SEASON_START (дата начала периода) |
| **Количество шагов** | ~4 (спектакль → охват → аудитория → сообщение) | 5 (возраст min → max → прикрепление → сводка → сообщение) | 3 (фильтры → прикрепление → сводка) | 8 (даты → спектакли → возраст min → max → статусы → прикрепление → сводка → сообщение) |
| **Обязательный период** | Нет (фильтрует за последний год автоматически) | Нет (вся история) | Нет (опционально через время сеансов) | **Да** (две даты обязательны) |
| **Фильтр по спектаклям** | Да (аудитория по выбранным спектаклям) | Нет | Да (опционально) | Да (опционально, включая неактивные) |
| **Фильтр по возрасту детей** | Нет | **Да, основной критерий** | Да (опционально) | Да (опционально) |
| **Фильтр по статусам билетов** | Только PAID и APPROVED | Только PAID и APPROVED | Да (опционально) | Да (опционально, по умолчанию PAID и APPROVED) |
| **Фильтр по типам мероприятий** | Нет | Нет | Да (опционально) | Нет |
| **Фильтр по сеансам** | Да (все или вручную по датам) | Нет | Да (опционально) | Нет (определяется периодом) |
| **Фильтр по конкретным билетам** | Нет | Нет | Да (ввод ID вручную) | Нет |
| **Видимость сеансов (on/off)** | Нет | Нет | Да (опционально) | Нет |
| **Вычисление возраста** | N/A | `date_part('year', age(birthdate))` — точный возраст | N/A | `round(child.age)` — округление к ближайшему чётному (banker's rounding) |
| **SQL-функция** | `_select_audience_rows()` | `_select_child_age_audience()` | `_select_ticket_holders_audience()` | `_select_season_audience()` |
| **Таблицы БД** | Ticket, UserTicket, User, ScheduleEvent | Ticket, UserTicket, User, PersonTicket, Person, Child | Ticket, UserTicket, User, ScheduleEvent (+ опционально PersonTicket, Person, Child) | Ticket, UserTicket, User, ScheduleEvent (+ опционально PersonTicket, Person, Child) |
| **Обязательное прикрепление спектакля** | Да | Нет | Нет (опционально) | Нет |
| **Минимальные шаги до аудитории** | 2 (спектакль + охват) | 1 (возраст) | 1 (фильтры) | 2 (дата начала + дата конца) |
| **Ключевое отличие** | Аудитория — те, кто **был** на спектаклях в этом году | Быстрый отбор по возрасту без привязки к периоду | Максимальная гибкость фильтров | Обязательный период + неактивные спектакли + выбор статусов + возраст по `Child.age` |

## Когда использовать каждый тип

### 1. WAS_THIS_YEAR_ON_PLAY
- Цель: предложить свободные места на спектакль тем, кто уже посещал похожие спектакли.
- Подходит для: повторных продаж, cross-selling между спектаклями.

### 2. CHILDREN_AGE
- Цель: быстро найти родителей детей определённого возраста по всей истории.
- Подходит для: возрастных акций, тематических рассылок (малыши, школьники и т.д.).
- **Не заменяется типом 4**, потому что тип 4 требует обязательный период.

### 3. TICKET_HOLDERS
- Цель: максимальная гибкость отбора аудитории.
- Подходит для: точечных рассылок по конкретным билетам, статусам, типам мероприятий.
- Уникальная возможность: ввод ID билетов вручную.

### 4. SEASON_TICKET_HOLDERS
- Цель: отобрать всех посетителей за конкретный период.
- Подходит для: анализа сезонной активности, рассылок по итогам сезона.
- Отличается от типа 2: обязательный период, все статусы билетов, доступ к неактивным спектаклям.
